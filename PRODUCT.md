# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Django (Python) with server-rendered HTML templates, CSS, and plain JavaScript for sidebar navigation. This stack was explicitly requested before the issue planning.

## Users
The initial audience is the people using Binux's internal CRM. Specific roles and permissions have not been decided.

## Product Purpose
An educational CRM project: build a navigable visual shell first, learn Django as it is built, and add real workflows and external service integrations in later, separately scoped phases.

## Capabilities and Constraints
Phase 1 contains exactly the five menu groups and 17 destinations in GitHub issues #1–#6. Every page is display-only and clearly marks fictional examples as demonstrations. No authentication, customer records, database-backed workflow, API integrations, real server/agent status, forms that submit, deployment, or external requests in this phase. Persian RTL interface; English issue descriptions and an educational Django walkthrough.

## Brand Commitments
The name is Binux CRM. The user provided a visual reference for a dark, right-aligned RTL sidebar with grouped navigation, icons, profile/search placeholders, and a collapse control; its original menu copy, branding, and personal data are not to be copied.

## Evidence on Hand
The five groups and exact Persian submenu labels are specified in issues #1–#6. No real customer, finance, contract, agent, or server data has been supplied; any examples must be explicitly fictional.

## Product Principles
- Learn through small, inspectable Django routes, views, templates, and tests.
- Make the page destination obvious without implying a functioning business workflow.
- Preserve room for future integration without building it prematurely.
